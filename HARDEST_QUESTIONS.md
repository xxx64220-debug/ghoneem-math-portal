# Hardest Questions loading

The report previously fetched all rows in sequential batches of 1,000 and rendered one table. Production query statistics observed on 29 September 2026 showed mean query times of about 5.6–6.6 seconds and maxima of about 7.6–7.8 seconds. An authenticated query plan also showed repeated nested staff permission checks for answers and question metadata.

The report now requests 50 rows plus one lookahead, ordered by track, rank and question ID. Pages are cached in memory for one minute, scoped to the signed-in user and selected track. Refresh clears that track's pages. Navigation cancels in-flight requests, and a 15-second timeout offers a retry instead of leaving a permanent loading screen. PDF and CSV exports fetch the complete selected report only when requested, including more than 1,000 rows, and fail instead of exporting a partial result.

Apply `supabase/sql/hardest_question_loading.sql` to enable a statement-cached administrator branch in the existing read policies of the six report tables and the equivalent cached administrator branch in the report view. It uses the existing database-backed `is_admin()` check, preserves the security-invoker view, existing policy commands and write checks, and other roles’ original predicates, and adds no write permissions. It does not modify any questions, keys, answers, scores or student records. Apply after `portal_upgrade.sql` (active-profile roles) and `fair_exam_keys.sql`. The patch also records the existing production grants for the two pure comparison helpers needed by the invoker view; it does not grant access to answer-key rows.

Verification: `node --test tests/hardest_questions.test.cjs tests/admin_question_reports.test.cjs tests/client_state.test.cjs`; database fixtures in `tests/hardest_questions.sql` cover SAT, EST1 and EST2, combined assigned/daily statistics, numeric aliases, incomplete quizzes, rank order, instructor scope, student key secrecy, and suspended administrators. All fixtures run only in an isolated database and roll back. Both new tests are included in CI.
