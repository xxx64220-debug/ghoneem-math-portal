# College Panda workbook: Chapter 2 (expressions)

29 source-numbered questions are in the SAT bank and Final Revision: Exercise 1 Q1–15 and Exercise 2 Q1–14. Source PDF pages 29–32; corresponding printed answers appear on PDF pages 315–317. Each question has its own source scan crop with original answer choices, a checked answer, and a concise algebra explanation.

Build with `python build.py ORIGINAL_PDF OUTPUT_SQL`. The builder checks the supplied PDF SHA-256, all exercise numbers, duplicate source codes and normalized stems, immutable keys, and revision linkage. The generated SQL and PDF are not committed.
