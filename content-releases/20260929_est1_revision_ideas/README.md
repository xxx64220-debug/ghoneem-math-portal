# EST I revision idea expansion — 29 September 2026

This additive release places 60 already verified EST I questions into Final Revision, each under a distinct, question-specific idea. It adds coverage in eight thin canonical lessons without changing question text, choices, answer keys, explanations, assets, exam membership, prior revision rows, sessions, or scores. EST II is not included.

`apply.sql` is a one-time guarded data release. It refuses to run if its release audit exists, any selected question is missing or no longer eligible, a selected content fingerprint differs, an idea is already present in its lesson, a selected question is already in revision, or the expected pre-release catalogue counts changed.

This is revision classification and curation only. Existing verification metadata is required, but the release does not claim a new independent certification of mathematical answers.
