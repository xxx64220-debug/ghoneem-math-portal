# EST I July 2026 recalled-question release

Adds 10 independently checked practice questions and one ungradable source hold to the existing EST I bank. Publishes a repeatable lesson exam, **EST I - July 2026 Recalled Questions - Verified Practice (10Q / 20 min)**, available to all three existing EST I groups and active EST I students without an EST I group. Optional untimed practice and repeatability follow the portal's existing lesson-exam behavior.

The source is an incomplete teacher recall, not the full official examination. Collection numbering is retained for traceability. The original rectangle and triangle graphics are included; answers remain in `question_keys`, never question assets. Item 2's incorrect numeric feedback is replaced with a verified symbolic-area MCQ, and item 7's missing correct choice is repaired to 840. Item 3 is evidence-only because missing coordinates and an undefined region prevent a unique area.

`apply.sql` contains the reviewed import packet. `review.json` records fidelity and corrections. Run `python3 verify_math.py` to independently check arithmetic, symbolic area and the defective source keys. `python3 dry_run.py` emits the identical release transaction ending in ROLLBACK for database verification. `apply.sql` commits that checked transaction, refuses replay/conflicts, and verifies unchanged existing questions and keys. Existing examinations, attempts and grades are preserved. The production receipt records the release readback: 10 eligible questions, one blocked source, a ready published exam, all three EST I groups assigned and 41 of 41 currently eligible enrollments able to open it. Production audit ID: 20419. No frontend deployment was necessary.
